# hongyp007.github.io

Personal academic website of YoungPyo Hong (M.S. student in astronomy, Seoul National University).

Live at **https://hongyp007.github.io**

A single static `index.html` (inline CSS and JavaScript, no build step or dependencies) served by GitHub Pages. Images, the CV and the link-preview card are in `assets/`.

To update: edit `index.html`, then

```bash
git add . && git commit -m "Update" && git push
```
